CÁC BƯỚC ĐÃ THỰC HIỆN (TỪ LÚC NHẬN YÊU CẦU ĐẾN NAY)
==================================================
Nếu bạn cần viết báo cáo hoặc giải trình cách làm, đây là toàn bộ các bước đã diễn ra:

* BƯỚC 1: KHỞI TẠO VÀ CÀI ĐẶT THƯ VIỆN
- Phân tích file PDF hướng dẫn.
- Chạy lệnh Terminal để cài đặt các thư viện cần thiết:
  `flutter pub add image_picker permission_handler video_player another_telephony flutter_contacts_service audioplayers`

* BƯỚC 2: CẤU HÌNH QUYỀN TRUY CẬP (PERMISSIONS)
- Mở file `android/app/src/main/AndroidManifest.xml`.
- Bổ sung 8 dòng `<uses-permission>` để khai báo cho hệ điều hành Android biết app sẽ sử dụng Camera, Bộ nhớ, Micro, SMS và Danh bạ.

* BƯỚC 3: THIẾT KẾ CẤU TRÚC GIAO DIỆN CHUNG
- Thay vì để mỗi bài tập là một project rời rạc, đã gom tất cả lại.
- Viết đè file `lib/main.dart` để tạo một giao diện có `Drawer` (menu điều hướng bên trái), giúp người dùng dễ dàng bấm chọn "Bài 1", "Bài 2"...

* BƯỚC 4: LẬP TRÌNH TỪNG CHỨC NĂNG (TẠO FOLDER lib/screens/)
- Viết `bai1_media_picker.dart`: Code chức năng chọn ảnh/video từ thư viện hoặc chụp trực tiếp. (Fix lỗi treo app khi load video).
- Viết `bai2_photo_capture.dart`: Code chức năng chụp ảnh và hiển thị full màn hình.
- Viết `bai4_video_recorder.dart`: Code chức năng quay video và phát video (Play/Pause).
- Viết `bai3_5_telephony.dart`: Kết hợp giao diện Đọc SMS và Quản lý danh bạ. Code xin quyền `Permission.sms` và `Permission.contacts`, sau đó lấy dữ liệu đổ ra danh sách (ListView).
- Viết `bai6_audio_player.dart`: Code sử dụng `audioplayers` để phát nhạc từ trong máy.

* BƯỚC 5: XỬ LÝ DỮ LIỆU ĐỂ TEST
- Tạo thư mục `assets/audios/`.
- Cấu hình file `pubspec.yaml` để nhận diện thư mục `assets/audios/`.
- Dùng lệnh tải trực tiếp 3 file mp3 từ Internet bỏ vào thư mục này.
- Hướng dẫn giả lập tin nhắn SMS và kéo thả ảnh vào máy ảo để có dữ liệu thử nghiệm.

* BƯỚC 6: KIỂM TRA LỖI (DEBUG & FIX)
- Fix lỗi thư viện danh bạ: Gỡ `flutter_contacts` bản mới, cài lại `flutter_contacts_service` bản cũ theo chuẩn giáo trình để không bị lỗi code.
- Chạy `flutter clean` và `flutter build apk` để dọn rác và đóng gói thành công.
